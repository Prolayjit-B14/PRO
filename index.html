Target: Writing synthesizable, race-condition free, clock-edge triggered logic files.

💾 Verilog RTL Code Selector

Select an RTL module to preview its behavioral source code and synthesizable gate footprint.

alu.v 
// 4-bit ALU module implementation
module alu (
  input [3:0] A, B,
  input [2:0] Op,
  output reg [3:0] Out,
  output reg CarryOut
);
  always @(*) begin
    case(Op)
      3'b000: {CarryOut, Out} = A + B; // ADD
      3'b001: Out = A - B;             // SUB
      3'b010: Out = A & B;             // AND
      3'b011: Out = A | B;             // OR
      default: Out = 4'b0000;
    endcase
  end
endmodule
